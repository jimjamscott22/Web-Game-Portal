Handoff · applying the skin to the other eight games

How to roll this out

Harvest is the default skin. Every screen reads from one set of CSS variables, so a game page is skinned by swapping hard-coded hexes for tokens — never by adding per-game colors.

1 · Set the tokens once

In src/index.css, replace the shadcn :root block with the Organic tokens plus the game additions below, and set Harvest as the default values. Load Caprasimo + Figtree; keep Pixelify Sans, it is now numerals only.

  • Design system: --color-bg, --color-surface, --color-text, --color-accent, --color-accent-2, --color-divider and the accent ramp steps.
  • Game additions: --t-board, --t-cell, --t-drop, --t-t2…--t-t64 (tile ladder) and --t-s1…--t-s9 (one hue per game, in the GAMES order).
  • Skins are four objects of the same keys. Write the chosen one to localStorage via the existing useLocalStorage hook and set the variables on <html>.

2 · Fix the shared components

Eight files carry the old pixel styling. Change them and every game page follows.

  • PixelButton.tsx → render .btn .btn-primary / .btn-secondary; drop the 3px ink border, keep a 0 4px 0 var(--t-drop) shadow as the pixel echo.
  • ScoreBox.tsx → 16px radius, accent fill for Score, surface + divider for Best, Pixelify numerals.
  • GameCard.tsx → 28px radius, no border, swatch panel from --t-s{n}, previews through .washed.
  • GameOverOverlay / WinOverlay → the dialog shown left: icon disc, Caprasimo title, score pair, stacked pill actions.
  • DifficultyPills, HowToPlayPanel, NavigationBar, Footer → .tag, .card, .nav.

4 · Rules that keep it coherent

Every board sits on --t-board with --t-cell holes Numerals are Pixelify, everything else Caprasimo or Figtree Radii: 999px controls, 16px cells, 28px containers Max two accents per board — the game hue and one ramp neighbour No hex in a component; if a value is missing, add a token Check every board in Dusk — that is where contrast breaks
